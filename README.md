## Getting Started

To get a copy of this project up and running on your local machine, follow these instructions.

### Prerequisites

You will need to have Docker and Docker Compose installed on your machine. You can download them from [Docker's website](https://www.docker.com/products/docker-desktop).

### Installing

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/your-repo-name.git
   ```
2. Navigate into the project directory
   ```bash
   cd your-repo-name
   ```
3. Build the Docker image
   ```bash
   docker-compose build
   ```
4. Run the Docker container
   ```bash
   docker-compose up
   ```

## Usage

Once the application is running, you can access it by navigating to `http://localhost:5000` in your web browser.
